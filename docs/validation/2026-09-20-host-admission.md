## 本批完成

- 此工作流预设的实际模型与角色派发路径增加 Host 准入；候选为 2 个活动根范围／同时根模型流、4 个子角色执行范围。默认配置仍关闭，未修改当前 Profile。
- 下一波角色必须整批取得名额，才允许提交并派发；不会先启动一半。提交失败在原生启动前撤销临时占位。
- 根流以迭代器实际结算为释放依据；取消信号不释放。角色及关联命令以持久化事实计数，停止未确认及重启后的旧范围仍占位。
- 人工结束只沿用既有原生门禁处置，不新增自动释放或更改 unknown／退出证据的渠道。
- 并发不足后暂停该根的旧响应，后台通知不能解封；后续原生用户消息才能重新尝试。原合同、门禁、版本及预算仍检查，没有自动排队或新增聊天框。
- 新增原生 `/workflow-resources` 只读查询；`stop` 仅停止当前根工作流，不调用模型、不扩容、不停止其他会话。`workflow_status` 可看到同一 Host 资源事实。

完整语义及不覆盖范围见 [设计边界](../design/workflow-host-admission-v1.md)，配置见 [资源候选说明](../operations/workflow-resource-policy.md)。这是此预设的执行准入，不是其他预设、辅助模型、OS 进程、总内存或供应商账单上限。
