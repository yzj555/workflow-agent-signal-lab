# 只读诊断与脱敏导出核验

日期：2026-09-20。结论：诊断工具本批候选验证通过，**实际数据报告仍为需要处理，不是全库健康或 Gate C 通过**。没有重启、发送模型任务、批准门禁或修改历史记录。

## 本批交付

- `scripts/diagnose-workflow.mjs`：维护 CLI；读取显式备份、对象目录、原生目录采集及允许的工作区，输出新的脱敏报告。私密编号对应表须额外指定，不混入可分享报告。
- `scripts/lib/workflow-diagnostics.mjs`：正式 Journal 解析器回放、原生根／子会话绑定、不可变对象摘要、授权工作区文件与撤销边界核对。没有启动、执行或修复能力。
- 现有原生只读采集补充完整根会话 ID 列表；未增加发送、取消或授权接口。
- 新增 20 项测试，覆盖缺失／过期／格式不符的采集、父子关系冲突、未知退出保留、坏行隔离、内容不一致、读取范围、大小写路径、撤销后比较、文件限额、路径重定向、私密字段隔离、新建导出与拒绝覆盖。

操作、字段含义和未覆盖范围见 [诊断使用说明](../operations/workflow-diagnostics.md)。

## 实际只读核对

使用同一最终候选读取 20 行、26 个 run；原生观察来自当前官方 3080 的只读列表与 control baseline。先保留仅允许插件工作区的报告，再显式加入此前创建的 12 个实验项目目录，没有授权整个磁盘。

| 观察 | 实际结果与边界 |
| --- | --- |
| Journal | 20 行全部通过当前协议回放，26 个 run 完成检查 |
| 原生目录 | 采集到 172 个根会话，没有活动任务报告；不是 OS 进程树全部退出的证明 |
| 历史目录 diagnostic | 共 55 项：2 corrupt、53 unavailable；其中 24 项关联这批工作流，均为 unavailable，且对应角色引用仍不可读；根因未凭分类推断 |
| 退出状态 | 2 项角色退出未知、2 项命令退出未完整结算；另外保留日志运行态与原生非活动观察之间的区别，没有补写已停 |
| 不可变对象 | 52 项引用内容核对相符；这是检查项数，不是 52 个不同物理文件 |
| 工作区文件 | 39 项与所比较的历史边界一致，25 项不同；差异可能来自后续编辑或其他运行，未判为损坏、未覆盖恢复 |
| 权限与数据保护 | 备份本体／旁文件、对象与检查点、原生采集及被核对的实验文件前后摘要不变；私密引用未出现在脱敏报告 |

最终诊断退出码为 **2／needs-attention**，不是 0。此前目录告警未消失，也没有被过滤成绿色。逐项原始证据、私密映射和导出校验只保存在本机，不纳入公开仓库。

本机验证清单位于 `.dsh/activation/workflow-diagnostics-20260920/`；分享版与私密映射分开保存在本机独立的诊断报告目录。正式发布前需人工检查可分享报告中的元数据。
