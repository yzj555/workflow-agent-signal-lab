## 实际维护结果

使用已拥有的无凭据合成 Home 和动态 loopback 端口。测试通过官方安装、公开 Host 服务及真实 Chromium 完成；没有自制聊天窗口，也没有真实模型调用。

| 场景 | 结果与限制 |
| --- | --- |
| RC.12 首次启动故意违反 HMR 策略 | 工作流在 Journal 提供前拒绝准入，ready／verified 均不成立，数据字节不变；测试恢复原策略全部字节，Host 正常退出 |
| 启动失败后恢复 RC.11 | 只恢复精确兼容代码，重新生成方案；原记录可见，不恢复数据库 |
| RC.11 正常升级到 RC.12 | 原记录保留；升级后通过合成夹具新增一条 Journal／一个 run、一段原生历史和一个工作区文件 |
| Host 持有 writer 时 capture | 真实安装脚本拒绝，工作流数据字节不变；不自动回收 owner |
| 误用升级前的旧数据检查点 | `current-data-changed` 拒绝；不能用旧库覆盖当前数据 |
| 捕获当前两条记录后回退 RC.11 | 旧目标完整解析当前 Journal、快照和全部 run；两段原生历史和新增文件保留 |
| 停用工作流 | 不加载工作流页签，两段原生对话仍可打开 |
| 实际卸载工作流包 | 已安装包不可解析，Journal、原生历史和工作区保留；浏览器仍可打开两段历史 |
| 重装 RC.11 后再升级 RC.12 | 逐次核对载荷和方案，两条记录仍可见；未复制旧数据回当前目录 |

六个最终浏览器场景均只有一个原生输入框、无水平溢出、零页面异常，所有测试 Host 正常退出。所有工作流记录仍处于未批准的需求阶段；兼容回执是 `compatibility-accepted-not-task-authorized`，不构成任务执行许可。

## 数据保留与缓存限制

Journal 保留检查覆盖 schema、每条完整记录、回放快照和所有 run 摘要，最终为 2 行／2 个 run。SQLite 正常关闭改变物理字节，但完整语义一致；浏览器读取期间的工作流文件摘要保持，不把语义一致说成全程字节不变。

新增原生会话的标题事件在日志中完整，但首次回退启动时列表显示“未命名”。这是冷列表读取滞后投影缓存的现象：测试在 `turn/end` 之后重命名，标题未进入该次检查点；按精确会话 ID 打开后，日志重放得到完整标题与内容。验收脚本不再将缓存标题作为会话身份，没有直接修改缓存或重新写标题来制造成功。[官方冷列表读取](https://github.com/deepseek-ai/deepseek-harness/blob/639ed015397290b3745d163aafe02ffee4aa3f84/packages/api/session-controller/src/list.ts)、[官方缓存检查点](https://github.com/deepseek-ai/deepseek-harness/blob/639ed015397290b3745d163aafe02ffee4aa3f84/packages/session/session-projection-cache/src/index.ts)

最终另以完整 Zstandard 帧只读解码，两段历史的原有六个事件、顺序和标题均存在。打开原生历史可能由 DSH 追加 `session/end-seed` 重放边界事件；本次各有一个，不是用户内容丢失，也不能宣称原生文件在整个演练期间从未变化。回退历史成功重放后，停用、卸载、重装和最终升级的原生文件与工作区字节均保持一致。原生列表缓存滞后仍作为已知上游表现保留，没有在插件中重复实现一套目录或修改 DSH 核心。

## 保留的失败与证据

初始脚本重复创建进度文件，在安装新版后提前结束；先核对实际版本与数据，再恢复测试代码，不回滚数据。第二轮在回退后的标题缓存定位处失败，日志核查和按 ID 重放后通过。续跑另发现 `pnpm remove` 不接受 `--ignore-scripts`，改用显式配置 `--config.ignore-scripts=true`；以及卸载普通文本输出误作 JSON。成功卸载后核对原状态，从现场继续重装。失败回执均保留，没有改写成全程一次通过。

本机可追溯证据位于 `.dsh/activation/`：RC.12 冻结源码与双构建、安装演练的 `transition-v2`、`web-compatible-rollback-resume-v1`、`transition-resume-v1`／`v2`／`v3` 及 `maintenance-final-v1`。最终绑定检查重新核对同归档、实际安装、当前数据、六个浏览器场景、原生压缩日志及工作区；主工程 src／tests／scripts／preset／lib、清单和锁保持本批起点，RC.9／RC.11 原归档摘要相同。
