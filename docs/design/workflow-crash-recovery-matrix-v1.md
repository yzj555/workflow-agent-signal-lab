# 工作中断与冷恢复：隔离跨进程验证

后续增量（2026-09-17）：下文是最初实验的范围；随后 R1/R2 已修复，四项测试已去掉夹具的提前 Session flush，改为验证产品入口自身的落盘屏障。候选与线上激活结果见 [后续交付记录](../../.dsh/activation/workflow-basic-production-20260917/verification.md)。原始失败和“已持久化”前置条件的历史结论继续保留，不改写为当时已经修复。

日期：2026-09-17。结论：**已持久化原生会话的四项有限恢复场景通过；完整生产准入仍未通过。** 新增四项自动化，连续两轮专项 4/4；后续全量结果与原失败分别保留，见 [本轮核验](../../.dsh/activation/workflow-crash-recovery-matrix-20260917/verification.md)。

## 验证结果

| 强停切点 | 必须成立的事实 | 本组结论 |
| --- | --- | --- |
| 子 Agent 正在等待脚本化模型结果 | 冷启动标为 unknown；无新模型调用、子 Agent 重建或自动推进；主动请求推进也被拒绝 | 通过 |
| 根模型活动中，仍有未结算的 5000ms 预留 | 只把原预留转为保守计入；停机等待超过 5250ms 不额外扣账；恰好到限只封闭一次，不伪造业务结果 | 通过 |
| 文件已写入、审查已完成，工程测试命令仍运行 | 文件、已完成审查与合同保留；命令和未完成角色为 unknown，退出码为空且没有退出／工具结算证明；不重跑、不自动撤销 | 通过 |
| 原生补额问题尚未回答 | 冷启动取消旧问题；迟到批准被拒绝，额度及已用量不变，不生成用户批准凭据 | 通过 |

四项均在初次冷恢复后再由两个全新进程依次打开／关闭。Workflow Journal 原始值摘要不变；不存在再次扣账、重复封闭、重新派发或重新批准。新 Host 故意关闭新建预算并提高默认额度，以证明旧账户仍受冻结上限约束。

每次强停后先证明旧 writer.lock **阻止新 Host 打开**。测试控制者等待自己持有的原 ChildProcess 退出，验证唯一临时目录和标记，再把旧标记改名留档；随后才执行冷恢复。这不是自动抢占锁，也不是已经交付了线上自动恢复入口。

## 实验边界

- 使用本地官方 DSH `0.1.5-rc.1`，核心 commit `183f08e9c6dde7e36cd2318eaee70b0da08fb35e`；AgentLoop、ToolRuntime、Questions、Workflow Engine、SQLite、PowerShell、local subprocess 均为真实组件。
- 模型为脚本化适配器、问题由夹具回答；Connection 路由和文件服务是测试适配器。实际文件写入唯一临时工作区。不验证真实模型质量、Web 鉴权或原生页面可用性，不消耗业务模型。
- 原生初始 Session 在任何 Run 建立前显式 flush。首次落盘窗口不在四项通过范围内；其失败样本和待确认风险见 [问题记录 R1](issues/crash-recovery-matrix-20260917.md)。
- 每个 Host 独立 Node 进程，最长 60 秒自退出；强停只针对本测试刚创建并持有的 ChildProcess。冻结测试及受控后代有 20 秒自退出保险，另有独立对照进程验证不被误停。
- 旧进程可能随 Windows 托管范围关闭或自行到期；本组不推断具体退出原因。新 Host 即使观察到 PID 消失，仍保持 unknown，不以 PID 消失冒充自己未持有的退出句柄凭据。
- 没有中断、重启、提交任务到当前 3080；没有写入其历史工作流，未改运行时源码、构建、预设或默认预算配置。全部测试记录与生产记录隔离。

## 仍缺少的证据

1. 首次会话落盘与 Journal 先后关系的真实原生入口核验；一次全量命令回收等待超时的原因，见 [问题记录](issues/crash-recovery-matrix-20260917.md)。
2. SQLite 提交内部、文件写入中／撤销事务中、返工复验及交付／沉淀中间态的更多精确切点。本组命令样本只证明“文件写完后、并行检查一侧完成”的恢复，不等于写入或撤销事务原子性。
3. 原生 Web／真实模型下对应切点、长运行负载和默认阈值，以及独立体验、安装升级回退。

当前仍为 P2 / 受控内部 Alpha。实验开关默认关闭；任何新的 3080 重启或活动中断都须另行说明范围并取得许可。

## 复跑

在插件根目录运行，每次使用新的标签，已有证据拒绝覆盖：

```powershell
node scripts/crash-recovery-matrix.mjs test new-focused-label
node scripts/crash-recovery-matrix.mjs native new-native-label
node scripts/crash-recovery-matrix.mjs full new-regression-label
```

`baseline/check` 固定保护本次的 Host、生产代码和历史记录，不是可跨版本任意执行的线上恢复工具。后续改了生产构建或真实数据时，应新建该次验证的保护基线，不得删除旧守卫来强行复跑。
