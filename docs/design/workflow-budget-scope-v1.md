## 生效规则

新增 Host 配置 `runBudgetScope`，按原生**根 Session ID**精确匹配，只决定新 Run 是否建立预算账户。

| 配置 | 新 Run 的预算行为 |
| --- | --- |
| `runBudgetEnabled: false` | 不新建预算账户，无论 scope 是什么 |
| 开关为 true，scope 缺省或 `[]` | 不新建预算账户，不自动扩展为全局 |
| 开关为 true，scope 为 ID 数组 | 只有数组内精确匹配的原生根会话可建账 |
| 开关为 true，scope 为字符串 `all` | 显式对全部符合原预设／根身份条件的新 Run 建账；在线实验不使用此项 |

以下是配置格式示例，不是当前活动配置；其中 ID 必须替换为实际取得的原生测试根会话 ID，不是页面标题：

```yaml
runBudgetEnabled: true
runBudgetScope:
  - '<实际原生测试根会话ID>'
runTimeBudgetEnabled: true
```

匹配成功时，次数限额与可选时长限额仍按 Host 配置随 `run/created` 原子冻结，且只建立一份根 Run 账户。子角色不需要加入名单，依其可信 lease 共享所属根的预算；它们不能作为协调者创建运行。时长具体口径见 [有效时长协议](workflow-run-time-v1.md)。

## 明确的隔离边界

- 不按标题、任务内容、工作区、前缀、大小写折叠或自然语言匹配；也不支持通配模式。用户 fork 得到新 Session ID，不因 `parentSession` 继承测试资格。
- 名单允许最多 128 个唯一 ID，每个长度 1～256。空 ID、首尾空白、控制字符、通配符字符 `* ? [ ]`、重复 ID、错误类型均拒绝配置，不退回全局。`null` 不是“空名单”。
- Host 启动时解析并复制冻结数组；修改调用方原数组不会改变已运行 Controller 的范围。合法范围不证明 ID 已存在，写错但格式合法的 ID 只会不命中。
- 仍需选择 Workflow Agent 预设并满足原生根身份校验；即使把其他预设或被委派 Agent 的 ID 写入名单，也不会授予协调、文件、命令或批准权限。
- 作用域只在建账入口使用，不在后续扣额入口过滤。**已有预算账户移出名单、总开关关闭或重启后仍照原冻结上限执行**；否则可以通过改配置绕过预算。
- 已存在但未计量的运行不会中途加账，草案改版也不会补造用量。只有正常结束后新建的 Run 才重新判断范围；原需求确认和执行门禁不被替代。
- scope 不是模型字段、RPC 写接口或用户自然语言授权。模型不能指定根 ID、scope 或开关来影响建账。

这里的“未启用”只表示不加入新预算实验，不表示阻止普通工作流执行；原有根响应、子角色、冻结命令监管照旧。它也不是独立 Host 或 OS 沙箱：共享 Host 的重启、存储故障仍可能影响其他会话，后续在线操作仍须排除其他活动并确认中断范围。

## 配置兼容说明

前一离线版本中，单独 `runBudgetEnabled: true` 会为全部新 Run 建账；现在必须另外给出非空名单或显式 `runBudgetScope: all`。这是有意收紧，防止漏填名单时扩大实验。原有隔离测试夹具已显式写 `all` 保持原测试意图，没有改变生产活动配置。持久化账户结构未新增字段，不迁移旧记录；前面时长字段自身的读取器降级限制仍然存在。

## 验证

新增 18 项测试（15 项作用域专项、3 项原生集成），全量从 288 升至 306：默认空范围、显式全量、配置校验与冻结、精确匹配、未选运行不写预算、已计量运行移出名单仍受限、扩展范围不回填旧草案、子角色共享、模型伪造拒绝、原生补额与冷恢复保留。

官方原生组件测试在**同一个隔离 Host**中验证：指定根请求到限，未选根可继续多次响应；指定根时长到限，另一个正在响应的未选根不被取消；用户 fork 不继承名单，其他预设与委派 Agent 不因名单获得权限。使用真实 AgentLoop／ToolRuntime／AgentRegistry、临时 SQLite 与脚本化 provider，没有真实模型调用。

官方依据是本地 DSH `0.1.5-rc.1`／`183f08e9c6dde7e36cd2318eaee70b0da08fb35e` 的 `packages/core/session/src/types.ts`（SessionId）、`packages/core/agent/src/index.ts`（AgentRegistry 原生身份与 parentAgent），以及现有预设／根身份校验。未修改 DSH 核心。

离线证据：[本片核验记录](../../.dsh/activation/workflow-budget-scope-20260916/verification.md)。最小在线机制验证已单独留档；下一步先修 [在线发现的通用呈现与备份问题](issues/budget-online-20260916.md)，再安排命令／时长耗尽和其他恢复矩阵。原有未知样本仍不动。
