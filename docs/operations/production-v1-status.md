# Production v1 执行与验收状态

更新：2026-10-08。用户已明确最终目标为**正式 Production v1**。本文件记录当前执行状态；各 Gate 的完整要求仍以 [生产准入计划](../design/workflow-production-readiness-v1.md) 为准，不复制或降低其标准。

## 完成的定义

在约定边界内，Gate A–E 全部通过；源码、测试、安装包、运行实例和文档对应同一发布基线，失败证据及已知限制可追溯。Alpha、可试用、单次 PASS、GitHub 源码公开或测试数量增加均不等于目标完成。

范围沿用既有约定：Windows、本地有人看护的 L0 文本和 L1 工程开发辅助；用户选择 DSH 预设，原生对话交流，原生门禁授权，插件只读可视化；固定角色与串并行、一次同范围返工、逐项沉淀。工具和上下文隔离不宣称为 OS 安全隔离。

任意动态 DAG、无限返工、无人值守生产服务操作、自动部署及外部数据库／云资源写入不进入 v1。为插件本身制作安装包，不代表工作流任务获得安装或发布权限。

## 正式接入方案已确定（2026-10-08）

用户选择**独立生产 Profile，完整保留当前实验 Profile 和全部旧档案**。生产 Profile 使用独立数据目录、安装与资源配置；不复制旧运行作为新运行、不改写历史结局或退出证据。旧格式只在副本上核查，原实验档案继续保留，不能将“已归档”标成“已修复”。

本次选择仅确定方案，尚未创建生产 Profile、迁移记录、重启服务或发送真实模型任务。新环境准备、实际切换和验收按各自明确范围执行；原 2026-09-20 撤销恢复激活许可已用完，不复用。Gate E 的目标相应为**新 Profile 可重复交付与旧档案完整保留**，不再要求先将旧 Profile 全量迁移后才能接入；历史不兼容及 I/O 根因未知仍单独列示，不能据此关闭 Gate C。
